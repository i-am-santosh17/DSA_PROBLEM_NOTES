# DSA_PROBLEM_NOTES

## What is this project?

**DSA_PROBLEM_NOTES** is a personal collection of handwritten (digitized) notes covering fundamental topics in **Data Structures and Algorithms (DSA)**. The notes are organized section-by-section as PDF files, making it easy to study each topic independently.

This repository is useful for:
- Beginners who want a structured introduction to DSA concepts
- Students preparing for coding interviews or competitive programming
- Anyone looking for quick, concise notes on core DSA topics

---

## 📚 Contents

| File | Description |
|------|-------------|
| `Know Basic Math.pdf` | Covers essential mathematical concepts required for DSA, such as number theory, prime numbers, GCD/LCM, modular arithmetic, and more |
| `Learn Basic Recursion.pdf` | Explains the fundamentals of recursion — how recursive functions work, base cases, call stacks, and common recursive patterns |

---

## 🚀 How to Use

1. Browse the repository and open the PDF file for the topic you want to study.
2. The notes are section-wise, so you can pick any topic and start learning.
3. It is recommended to start with **Basic Math** before moving on to **Recursion**, as math concepts are often used in recursive problems.

---

## 🗂️ Topics Covered

- **Basic Math** — Number theory, primes, divisors, GCD, LCM, modular arithmetic
- **Recursion** — Recursive thinking, base cases, recursion tree, common patterns

More sections will be added over time.
